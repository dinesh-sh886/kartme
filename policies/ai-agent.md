# OpenCode AI Agent Policy

1. Read root `AGENTS.md`, product docs, decision register, service boundaries, risk register and policies before work.
2. Work only on the explicitly requested phase/task.
3. P00 is documentation/governance only. Do not generate application code or start P01 until P00 is explicitly accepted.
4. No automatic phase progression, release publication, production deployment, background workers or destructive operations.
5. Never reset branches, force-push, delete user data, overwrite unreviewed work or run destructive migrations without explicit authorization.
6. Inspect Git status and current changes before editing. Preserve user changes.
7. Ask before deciding unresolved security, money, tenancy, consistency, data retention or service-boundary questions.
8. Never invent test, build, scan, deployment, review or approval evidence.
9. Report exact files changed, commands run, results, gaps, risks and next approval needed.
10. Public repository commits require secret/staged-diff review and passing required checks.
