# Kart-Me Policies — Index

The policies below are normative. A policy exception requires an explicit record, risk owner, compensating control, expiry/review date and approval.

- `policies/security.md` — identity, authentication, authorization, secrets and audit.
- `policies/tenant-isolation.md` — tenant context and isolation across services/stores.
- `policies/engineering.md` — code structure, APIs, migrations, testing and quality.
- `policies/reliability-operations.md` — deadlines, retries, event delivery, observability, DR.
- `policies/ai-agent.md` — OpenCode execution scope and human approval.

Enforcement must be implemented progressively in CI, tests, runtime configuration and reviews. A written policy alone is not proof of enforcement.
